开始使用

What is TaskSSH?

TaskSSH 是一个基于 SSH 的轻量级批量运维工具。整个程序编译为单个可执行文件， 无外部依赖，无需安装 agent。通过 inventory.yaml 声明服务器组与变量， 即可对一批主机批量执行命令、上传文件、下载日志，或将多个步骤编排成完整任务。

内建 command / push / fetch / script 四种原子 action，可独立使用，亦可组合为有序流程。任务定义即配置，可提交、可审查、 可复用于多环境发布。

核心特性

原子能力

📁

目录传输

push / fetch 支持目录。默认递归逐文件，加 -z 则打包传输。

🔑

密码加密

AES-256-GCM 加密清单中的密码。密钥由用户管理，不硬编码在二进制中。

📦

按组分批

通过 serial 与 min_available 控制每批主机数与安全余量，支持滚动部署与回退。

快速开始

从一条命令到完整流程，按需选用

1

直接执行

无需配置文件，位置参数指定主机，-u / -p 传入认证信息。

2

按组执行

创建 inventory.yaml 声明服务器组与变量，用组名批量执行。

3

执行任务

在清单中定义 tasks，把多个步骤编排成流程，一条命令完成。

示例：直接执行

taskssh command 10.0.0.1 -u deploy -e "uptime" -y

示例：定义任务

tasks:
  release:
    steps:
      - name: "上传新版本"
        action: push
        with:
          file: "./dist/{{app_name}}-{{version}}.jar"
          dest: "{{service_path}}"
          force: true
      - name: "重启服务"
        action: command
        with:
          command: "systemctl restart {{app_name}}"
        delay: 5
      - name: "健康检查"
        action: command
        with:
          command: "curl -sf http://localhost:8080/health"

执行：taskssh release prod -i inventory.yaml -y

内置 Action

四种原子 Action，覆盖常规批量运维场景

command

执行远程命令

taskssh command prod -e "ls -la /opt"

push

上传文件或目录到远程

taskssh push prod -f app.jar -d /opt/app/

fetch

从远程下载文件或目录

taskssh fetch prod -f /var/log/app.log -d ./logs/

script

上传本地脚本并执行

taskssh script prod -f ./deploy.sh -r
