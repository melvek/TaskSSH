任务编排

不止能执行一条命令。把多个操作串成有序流程，一条命令搞定。

📄

配置即文档

整个流程写在 YAML 里，新人看配置就知道发布流程。

🧩

原子能力

command / push / fetch 三个 Action 自由组合。

🔀

变量替换

一套配置适配多套环境，同一任务部署到 prod / uat。

🛡️

严格模式

🔑

多认证方式

密码、公钥、私钥口令，或终端交互输入。

三步上手

从下载到执行，不超过 5 分钟

1

下载

从 GitHub Releases 下载，或 go build -o taskssh main.go 构建。

2

写清单

创建 inventory.yaml，定义服务器组和任务。

3

执行

taskssh release prod -y，一条命令搞定。

示例：发布流程

tasks:
  release:
    steps:
      - name: "上传新版本"
        action: push
        with:
          file: "./dist/${app_name}-${version}.jar"
          dest: "${service_path}"
          force: true
          backup: true
      - name: "重启服务"
        action: command
        with:
          command: "systemctl restart ${app_name}"
        delay: 5
      - name: "健康检查"
        action: command
        with:
          command: "curl -sf http://localhost:8080/health"

执行：taskssh release prod-trans -i inventory.yaml -y

内置任务

三种原子 Action，覆盖绝大多数批量运维场景

command

执行远程命令

taskssh command prod -e "ls -la /opt"

push

上传文件到远程

taskssh push prod -f app.jar -d /opt/app/

fetch

从远程下载文件

taskssh fetch prod -f /var/log/app.log -d ./logs/
