为什么用 TaskSSH

单文件、无依赖，将批量操作编写为可复用的流程

⚙️

任务编排

将一个或多个操作组合为有序流程。命令执行、上传、下载可自由组合，由单条命令触发执行。

📄

配置即文档

完整流程写入 inventory.yaml，可提交、可审查，便于团队理解发布流程。

🧩

原子能力

内建 command / push / fetch / script 四种 action，可独立使用，亦可组合为流程。

📁

目录传输

push / fetch 支持目录。默认递归逐文件，加 -z 则打包传输。

🔑

密码加密

AES-256-GCM 加密清单中的密码。密钥由用户管理，不硬编码在二进制中。

🔍

Dry-run

--dry-run 显示每台主机每个步骤将执行的内容，不实际执行，便于执行前确认。

快速开始

创建密钥、定义清单、执行任务

1

创建密钥文件

用于加密清单中的密码。只需创建一次：openssl rand -base64 32 > ~/.taskssh/vault-key

2

定义清单

创建 inventory.yaml，声明服务器组、主机及任务步骤。

3

执行任务

运行 taskssh release prod -y，按清单定义完成整个流程。

示例：发布流程

tasks:
  release:
    steps:
      - name: "上传新版本"
        action: push
        with:
          file: "./dist/${app_name}-${version}.jar"
          dest: "${service_path}"
          force: true
      - name: "重启服务"
        action: command
        with:
          command: "systemctl restart ${app_name}"
        delay: 5
      - name: "健康检查"
        action: command
        with:
          command: "curl -sf http://localhost:8080/health"

执行：taskssh release prod -i inventory.yaml -y

内置任务

四种原子 Action，覆盖常规批量运维场景

command

执行远程命令

taskssh command prod -e "ls -la /opt"

push

上传文件或目录到远程

taskssh push prod -f app.jar -d /opt/app/

fetch

从远程下载文件或目录

taskssh fetch prod -f /var/log/app.log -d ./logs/

script

上传本地脚本并执行

taskssh script prod -f ./deploy.sh -r
